# JamStudio Project Context

## Vision

JamStudio is a professional cross-platform Digital Audio Workstation (DAW)
designed to combine recording, editing, notation, live performance,
and AI-assisted music production into a single application.

The goal is to eliminate the need for musicians to constantly switch
between multiple applications.

## Primary Goals

- Professional multitrack recording
- MIDI recording and editing
- Guitar tablature generation
- Standard music notation
- Drum notation
- Chord charts
- AI-assisted workflows
- Live performance mode
- Multiple cue mixes
- Cross-platform support

## Supported Platforms

- Linux
- Windows
- macOS

## Primary Technologies

- C++20
- Qt 6
- JUCE
- CMake
- Git
- GitHub

## Design Philosophy

Professional software.

Maintainable.

Modular.

Fast.

Reliable.

Extensible.

Every major subsystem should be independent whenever possible.

The project should favor long-term maintainability over short-term speed of development.
