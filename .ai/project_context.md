# JamStudio Project Context

## Vision

JamStudio is a music practice and learning workstation. Load any song,
split it into playable stems, read along with synced tabs or sheet music,
practice with a metronome, and record yourself — all in one application.

The long-term goal is to combine recording, editing, notation, live
performance, and AI-assisted music production into a single application,
eliminating the need for musicians to constantly switch between tools.

## Primary Goals

- Professional multitrack recording
- MIDI recording and editing
- Guitar tablature generation
- Standard music notation
- Drum notation
- Chord charts
- AI-assisted workflows
- Live performance mode
- Multiple cue mixes
- Cross-platform support

## Supported Platforms

- Linux
- Windows
- macOS

## Primary Technologies

- C++20
- Qt 6
- JUCE
- CMake
- Git
- GitHub

## Design Philosophy

Professional software.

Maintainable.

Modular.

Fast.

Reliable.

Extensible.

Every major subsystem should be independent whenever possible.

The project should favor long-term maintainability over short-term speed of development.
