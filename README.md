# JamStudio

Cross-platform music production, notation, live performance, and AI-assisted music creation software.

Desktop builds:

- **macOS** — `./scripts/package-macos.sh` produces a disk image. Needs current Xcode Command Line Tools, CMake, and `brew install ffmpeg`. See `scripts/README-PACKAGING.md`.
- **Linux** — `./scripts/package-linux-appimage.sh`
- **Windows** — `.\scripts\package-windows.ps1`
